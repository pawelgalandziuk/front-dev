Introduction

Welcome to the Frontend Developer Guide.

This guide will help you understand the basics of frontend development, including HTML, CSS, and JavaScript.

Week 1 - HTML Structure

1. First of all

Each .html file has to start with this structure:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Your Page Title</title>
</head>
<body>
    <!-- Your content goes here -->
</body>
</html>
  • <!DOCTYPE html> -- Says to the browser: Its HTML5.
  • <html lang="en"> -- The root element of the HTML document, with a language attribute set to English.
  • <head> -- Contains meta-information about the document, such as character encoding and viewport settings.
    It can also contain <link>, which is an element used to link external resources like CSS files.
  • <meta charset="UTF-8"> -- Specifies the character encoding for the document, ensuring that it can display a wide range of characters correctly.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> -- Ensures that the webpage is responsive and scales correctly on different devices, particularly mobile devices.
  • <title>Your Page Title</title> -- Sets the title of the webpage, which appears in the browser tab and is important for SEO.
  • <body> -- Contains the content of the HTML document that is visible to users, such as text, images, and other elements.

2. HTML Elements

HTML elements are the building blocks of web pages. They are represented by tags, which define the structure and content of the page.

  • <h1> to <h6> -- Heading elements, with <h1> being the most important and <h6> the least.
  • <p> -- Paragraph element, used for blocks of text.
  • <a> -- Anchor element, used for creating hyperlinks to other pages or resources.
  • <img> -- Image element, used to embed images in the page.
  • <ul>, <ol>, and <li> -- List elements, used for unordered and ordered lists.
  • <div> -- Division element, used as a container for grouping other elements together.
  • <span> -- Inline container element, used for styling or grouping text within other elements.
  • <form> -- Form element, used for collecting user input through various form controls.
  • <input> -- Input element, used for various types of user input within a form.
  • <button> -- Button element, used to create clickable buttons for user interaction.
  • <table>, <tr>, <td> -- Table elements, used for displaying tabular data.
  • <iframe> -- Inline frame element, used to embed another HTML page within the current page.
  • <script> -- Script element, used to include JavaScript code in the page.
  • <a href="URL"> -- Anchor element with a hyperlink reference, used to link to other pages or resources.

3. Semantic HTML5

Semantic HTML5 elements provide meaning to the structure of a webpage, making it easier for browsers and assistive technologies to understand the content.

  • <header> -- Represents introductory content or a set of navigational links.
  • <nav> -- Represents a section of the page intended for navigation links.
  • <main> -- Represents the main content of the document, unique to the page.
  • <section> -- Represents a standalone section of content, typically with a heading.
  • <article> -- Represents a self-contained piece of content that could be distributed independently.
  • <aside> -- Represents content that is tangentially related to the main content, such as sidebars or callouts.
  • <footer> -- Represents footer content for its nearest sectioning element, often containing metadata or links.

5. Keys attributes

Some key attributes in HTML include:

  • id -- A unique identifier for an element, used for styling and scripting.
  • class -- A class name that can be shared by multiple elements, used for styling and scripting.
  • src -- Specifies the source URL for media elements like images and scripts.
  • href -- Specifies the URL for anchor elements, linking to other pages or resources.
  • alt -- Provides alternative text for images, improving accessibility.
  • title -- Provides additional information about an element, often displayed as a tooltip.

6. HTML Tables

HTML tables are used to display tabular data. They consist of rows and columns defined by various table elements.

  • <table> -- The container for table elements.
  • <tr> -- Defines a table row.
  • <th> -- Defines a table header cell.
  • <td> -- Defines a table data cell.

7. HTML Media

HTML media elements allow you to embed audio and video content into your web pages.

  • <audio> -- Embeds audio content, with controls for playback.
  • <video> -- Embeds video content, with controls for playback.
  • <source> -- Specifies multiple media sources for audio and video elements.

8. HTML Iframes

HTML iframes allow you to embed another HTML document within the current page.

  • <iframe> -- Embeds an external HTML document within the current page.
  • src -- Specifies the URL of the document to be embedded.
  • width and height -- Define the dimensions of the iframe.

9. More useful elements

A few extra elements that come up often and are good to know:

  • <figure> and <figcaption> -- Groups media (like an image) together with a caption describing it.
  • <blockquote> -- Marks a section as a quotation from another source.
  • <details> and <summary> -- Creates a native expandable/collapsible section, no JavaScript needed.

Summary

In summary, HTML is the foundation of web development, providing the structure and content of web pages. Understanding HTML elements, attributes, and semantic structure is essential for creating accessible and well-structured websites.

Week 2 - CSS Styling

CSS (Cascading Style Sheets) controls how HTML elements look and how they are arranged on a page. It is used for colors, fonts, spacing, borders, sizes, and layouts.

1. CSS Syntax

A CSS rule consists of a selector and one or more declarations:

selector {
    property: value;
}

For example:

p {
    color: navy;
    font-size: 1rem;
}
  • p -- The selector. It chooses which HTML elements will be styled.
  • color and font-size -- Properties that describe what will change.
  • navy and 1rem -- Values assigned to the properties.
  • ; -- Separates declarations. It should be added after every declaration.

CSS comments are written like this:

/* This is a CSS comment */

2. Three Ways to Add CSS

Inline CSS

<p style="color: red;">Red text</p>

Inline CSS affects one element. It is useful for quick experiments, but it becomes difficult to maintain when used throughout a page.

Internal CSS

<head>
    <style>
        p {
            color: red;
        }
    </style>
</head>

Internal CSS is placed inside a <style> element in the document's <head>. It is suitable for small pages and exercises.

External CSS

<link rel="stylesheet" href="style.css">

The link is placed inside <head>, while the rules are stored in a separate style.css file:

p {
    color: red;
}

An external stylesheet is usually the best option because it separates the HTML structure from its appearance and can be reused by multiple pages.

3. CSS Selectors

Selectors tell the browser which elements should receive a set of styles.

  • p { ... } -- Selects every <p> element.
  • .card { ... } -- Selects every element with class="card". Classes can be reused.
  • #contact { ... } -- Selects the element with id="contact". An ID must be unique on the page.
  • .card p { ... } -- Selects every paragraph located inside an element with the card class.
  • h1, h2, h3 { ... } -- Applies the same declarations to several selectors.
  • * { ... } -- The universal selector; it selects every element.

Use classes for reusable styles. IDs are mainly useful for unique page targets, labels, and JavaScript hooks.

<article class="card featured" id="first-card">
    Card content
</article>

An element may have more than one class, separated by spaces.

4. Pseudo-classes

A pseudo-class selects an element in a particular state:

a:hover {
    color: red;
}

input:focus {
    outline: 3px solid royalblue;
}

button:active {
    transform: scale(0.98);
}

li:first-child {
    font-weight: bold;
}
  • :hover -- The pointer is over the element.
  • :focus -- The element has keyboard or input focus.
  • :focus-visible -- Focus should be visibly indicated, usually during keyboard navigation.
  • :active -- The element is currently being activated, for example while a button is pressed.
  • :first-child and :last-child -- Select an element according to its position among siblings.

Never remove a focus outline without providing another clearly visible focus style. Keyboard users need it to know which control is active.

5. The Cascade, Specificity, and Inheritance

The word "cascading" describes how the browser chooses between competing rules. It considers importance, selector specificity, and source order.

  1. Inline styles are more specific than ordinary stylesheet rules.
  2. An ID selector such as #warning is more specific than a class.
  3. A class or pseudo-class such as .note or :hover is more specific than an element selector.
  4. An element selector such as p has the lowest specificity in this list.
  5. When specificity is equal, the rule written later wins.
p { color: blue; }
.note { color: green; }
#warning { color: red; }

A paragraph with both class="note" and id="warning" will be red. Avoid !important in normal code because it makes future overrides harder.

Some properties, especially color and font-family, are inherited by child elements. Layout properties such as margin, padding, and border are generally not inherited.

6. The Box Model

Every HTML element is treated as a rectangular box made of four layers:

  1. content -- The text, image, or other content.
  2. padding -- Space between the content and border.
  3. border -- The line surrounding the padding and content.
  4. margin -- Space outside the border, separating the element from its neighbors.
.card {
    width: 300px;
    padding: 20px;
    border: 2px solid black;
    margin: 30px;
}

With the default content-box sizing, the visible width is 300px + 40px padding + 4px border = 344px. Margin adds space around that box.

A common reset makes declared widths include the padding and border:

* {
    box-sizing: border-box;
}

With border-box, the same element has a total visible width of 300px.

Spacing shorthand

padding: 20px;                 /* all sides */
padding: 10px 20px;            /* top/bottom, left/right */
padding: 10px 20px 30px;       /* top, left/right, bottom */
padding: 10px 20px 30px 40px;  /* top, right, bottom, left */

The same shorthand rules apply to margin. Individual sides can be set with properties such as margin-top, padding-left, and border-bottom.

7. Width and Height

.container {
    width: 90%;
    max-width: 1000px;
    min-height: 300px;
    margin: 0 auto;
}
  • width and height -- Set preferred dimensions.
  • min-width and min-height -- Prevent an element from becoming smaller than a limit.
  • max-width and max-height -- Prevent an element from becoming larger than a limit.
  • margin: 0 auto -- Horizontally centers a block that has a limited width.

Avoid a fixed height for text containers unless it is truly required. Growing content can overflow a box with a fixed height.

8. CSS Units

  • px -- A fixed CSS pixel. It is useful for borders and small visual details.
  • % -- A percentage usually calculated from a related size of the parent element.
  • rem -- Relative to the root <html> font size. By default, 1rem is usually 16px.
  • em -- Relative to the current element's font size. It is useful when spacing should scale with a component's text.
h1 {
    font-size: 2rem;
}

button {
    font-size: 1rem;
    padding: 0.5em 1em;
}

img {
    width: 100%;
}

A practical starting point is to use rem for typography and most spacing, percentages for flexible widths, px for fine details, and em for dimensions tied to a component's font size.

9. Colors

color changes the foreground text color, while background-color changes the background.

.example {
    color: #222222;
    background-color: rgb(245, 245, 245);
    border-color: hsl(210, 50%, 40%);
}

Common color formats include named colors such as red, hexadecimal values such as #ff0000, rgb(), rgba() with transparency, and hsl().

Repeated colors can be stored in custom properties:

:root {
    --color-primary: #176b4d;
    --color-text: #202020;
    --color-background: #f4f1ea;
}

body {
    color: var(--color-text);
    background-color: var(--color-background);
}

Always maintain strong contrast between text and its background so that the content remains readable.

10. Fonts and Text

body {
    font-family: Georgia, "Times New Roman", serif;
    font-size: 1rem;
    line-height: 1.6;
}

h1 {
    font-size: 2.5rem;
    font-weight: 700;
    text-align: center;
}
  • font-family -- Sets the typeface. Provide fallback fonts and finish with a generic family such as serif or sans-serif.
  • font-size -- Sets the text size.
  • font-weight -- Sets thickness, commonly 400 for regular and 700 for bold.
  • line-height -- Controls vertical space between lines.
  • text-align -- Aligns inline content left, right, or center.
  • text-decoration -- Adds or removes decorations such as underlines.
  • text-transform -- Changes capitalization, for example with uppercase.

11. Block, Inline, and Display

Block elements such as <div>, <section>, and <p> normally begin on a new line and use the available width. Inline elements such as <span> and <a> flow within a line and use only the space their content needs.

a {
    display: inline-block;
}

.hidden {
    display: none;
}
  • display: block -- Creates a block-level box.
  • display: inline -- Creates an inline box; width and height do not behave like they do on a block.
  • display: inline-block -- Flows inline but accepts dimensions and padding like a block.
  • display: none -- Removes the element from both the page and its layout.
  • display: flex -- Turns an element into a Flexbox container.

12. Flexbox Basics

Flexbox arranges a group of items along one main direction. The parent is the flex container, and its direct children are flex items.

<div class="cards">
    <article class="card">First</article>
    <article class="card">Second</article>
    <article class="card">Third</article>
</div>
.cards {
    display: flex;
    flex-direction: row;
    gap: 1rem;
}

Direction and axes

  • row -- Items run horizontally. This is the default.
  • row-reverse -- Items run horizontally in reverse order.
  • column -- Items run vertically.
  • column-reverse -- Items run vertically in reverse order.

With flex-direction: row, the main axis is horizontal and the cross axis is vertical. With column, the axes switch.

Alignment

.cards {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

justify-content aligns items on the main axis. Common values are flex-start, center, flex-end, space-between, space-around, and space-evenly.

align-items aligns items on the cross axis. Common values are stretch, flex-start, center, and flex-end.

Wrapping and gaps

.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}

flex-wrap: wrap allows items to move onto a new line when there is not enough room. gap adds consistent spacing between items without requiring margins on every child.

Flexible item sizes

.card {
    flex: 1 1 250px;
}

This is shorthand for flex-grow: 1, flex-shrink: 1, and flex-basis: 250px. The card starts around 250px wide, may grow into free space, and may shrink when necessary.

14. Responsive Images

img {
    display: block;
    max-width: 100%;
    height: auto;
}

This prevents an image from becoming wider than its container while preserving its original proportions.

16. Browser Developer Tools

Press F12 or open the browser's developer tools and select the Elements or Inspector tab. Developer tools allow you to:

  • Inspect which CSS rules apply to an element.
  • See overridden declarations shown with a line through them.
  • Edit values temporarily and observe the result immediately.
  • Inspect an element's box model.
  • Visualize and debug Flexbox layouts.
  • Test the page at different viewport widths.

Changes made in developer tools disappear when the page is refreshed, so transfer successful experiments into the stylesheet.

Summary

After this week, you should understand how to attach CSS, write rules with selectors, resolve competing styles, use the box model, choose suitable units, style colors and typography, and build a wrapping layout with Flexbox. You should also be able to explain the difference between margin and padding, classes and IDs, rem and em, and justify-content and align-items.
