Week 1 - HTML Structure

1. First of all

Each .html file has to start with this structure:


                    <!DOCTYPE html>
                    <html lang="en">
                    <head>
                        <meta charset="UTF-8">
                        <meta name="viewport" content="width=device-width, initial-scale=1.0">
                        <title>Your Page Title</title>
                    </head>
                    <body>
                        <!-- Your content goes here -->
                    </body>
                    </html>
  • <!DOCTYPE html> -- Says to the browser: Its HTML5.
  • <html lang="en"> -- The root element of the HTML document, with a language attribute set to English.
  • <head> -- Contains meta-information about the document, such as character encoding and viewport settings.
    It can also contain <link>, which is an element used to link external resources like CSS files.
  • <meta charset="UTF-8"> -- Specifies the character encoding for the document, ensuring that it can display a wide range of characters correctly.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0"> -- Ensures that the webpage is responsive and scales correctly on different devices, particularly mobile devices.
  • <title>Your Page Title</title> -- Sets the title of the webpage, which appears in the browser tab and is important for SEO.
  • <body> -- Contains the content of the HTML document that is visible to users, such as text, images, and other elements.

2. HTML Elements

HTML elements are the building blocks of web pages. They are represented by tags, which define the structure and content of the page.

  • <h1> to <h6> -- Heading elements, with <h1> being the most important and <h6> the least.
  • <p> -- Paragraph element, used for blocks of text.
  • <a> -- Anchor element, used for creating hyperlinks to other pages or resources.
  • <img> -- Image element, used to embed images in the page.
  • <ul>, <ol>, and <li> -- List elements, used for unordered and ordered lists.
  • <div> -- Division element, used as a container for grouping other elements together.
  • <span> -- Inline container element, used for styling or grouping text within other elements.
  • <form> -- Form element, used for collecting user input through various form controls.
  • <input> -- Input element, used for various types of user input within a form.
  • <button> -- Button element, used to create clickable buttons for user interaction.
  • <table>, <tr>, <td> -- Table elements, used for displaying tabular data.
  • <iframe> -- Inline frame element, used to embed another HTML page within the current page.
  • <script> -- Script element, used to include JavaScript code in the page.
  • <a href="URL"> -- Anchor element with a hyperlink reference, used to link to other pages or resources.

3. Semantic HTML5

Semantic HTML5 elements provide meaning to the structure of a webpage, making it easier for browsers and assistive technologies to understand the content.

  • <header> -- Represents introductory content or a set of navigational links.
  • <nav> -- Represents a section of the page intended for navigation links.
  • <main> -- Represents the main content of the document, unique to the page.
  • <section> -- Represents a standalone section of content, typically with a heading.
  • <article> -- Represents a self-contained piece of content that could be distributed independently.
  • <aside> -- Represents content that is tangentially related to the main content, such as sidebars or callouts.
  • <footer> -- Represents footer content for its nearest sectioning element, often containing metadata or links.
    • Tag When to use When NOT to use
    div Layout wrapper, use when no semantic element is suitable. Instead of section/article/nav
    section Grouping related content, typically with a heading. For generic containers without a specific purpose.
    article Self-contained content that could be distributed independently. For content that is not independent or standalone.

5. Keys attributes

Some key attributes in HTML include:

  • id -- A unique identifier for an element, used for styling and scripting.
  • class -- A class name that can be shared by multiple elements, used for styling and scripting.
  • src -- Specifies the source URL for media elements like images and scripts.
  • href -- Specifies the URL for anchor elements, linking to other pages or resources.
  • alt -- Provides alternative text for images, improving accessibility.
  • title -- Provides additional information about an element, often displayed as a tooltip.

6. HTML Tables

HTML tables are used to display tabular data. They consist of rows and columns defined by various table elements.

  • <table> -- The container for table elements.
  • <tr> -- Defines a table row.
  • <th> -- Defines a table header cell.
  • <td> -- Defines a table data cell.

7. HTML Media

HTML media elements allow you to embed audio and video content into your web pages.

  • <audio> -- Embeds audio content, with controls for playback.
  • <video> -- Embeds video content, with controls for playback.
  • <source> -- Specifies multiple media sources for audio and video elements.

8. HTML Iframes

HTML iframes allow you to embed another HTML document within the current page.

  • <iframe> -- Embeds an external HTML document within the current page.
  • src -- Specifies the URL of the document to be embedded.
  • width and height -- Define the dimensions of the iframe.

Summary

In summary, HTML is the foundation of web development, providing the structure and content of web pages. Understanding HTML elements, attributes, and semantic structure is essential for creating accessible and well-structured websites.
